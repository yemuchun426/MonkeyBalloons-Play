# Party Display font

A small character subset of ZCOOL KuaiLe Regular by the ZCOOL KuaiLe Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/zcoolkuaile
License: SIL Open Font License 1.1; see OFL.txt distributed beside the font.

party-display.ttf contains only the game settlement/UI glyphs and digits, generated using fontTools.subset. It is self-hosted by the build and does not contact a font CDN. Add required glyphs when changing display-font text.
